# Calculadora de Gado a Pasto

Aplicativo estático/PWA para estimar ganho de peso de bovinos a pasto.

## Recursos
- Boi e vaca com preço por kg informado manualmente.
- GMD editável, padrão 0,50 kg/dia.
- Peso final estimado.
- Ganho bruto por animal e por lote.
- Histórico de até 100 registros salvo no navegador.
- Layout responsivo para celular e computador.
- PWA instalável quando servido por HTTPS.
